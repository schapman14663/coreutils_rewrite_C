# coreutils_rewrite_C
A personal rewrite of coreutils functions in C as part of my PDP

Since I'm learning C, I feel like a good place to start with
some projects would be to recreate some of the coreutils, the
plan is to do this in stages. Starting with basics, filestreams,
reading bytes, handling stdin, stdout, stderr, then move on to 
inspecting files and data operations, then directory operations.

## Basics:

- [ ] echo
- [ ] cat
- [ ] head 
- [ ] tail 

## Inspecting Files:

- [ ] wc 
- [ ] grep 
- [ ] sort 

## Directory Operations:

- [ ] cd
- [ ] mv
- [ ] rm 
- [ ] mkdir
- [ ] ls
